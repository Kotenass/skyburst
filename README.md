# Skyburst

Вертикальный аркадный тап-шутер для Android (Kotlin + SurfaceView/Canvas).  
Это **отдельная** игра: не Rushfire и не ToiGo.

## Об игре

Вы управляете неоновым кораблём внизу экрана. Сверху накатывают волны врагов и метеоритов.  
Стреляйте по врагам, **уворачивайтесь от метеоритов** (их нельзя уничтожить).  
Счёт = время выживания + убийства. Рекорд хранится локально (SharedPreferences).  
Сложность растёт: быстрее и плотнее волны.

## Управление

Держи палец на экране и веди **влево-вправо** — корабль едет за пальцем по горизонтали. Пока держишь — идёт огонь. Вверх-вниз корабль не двигается.

Экраны: **Старт** + **Рекорд** → игра (HUD со счётом) → **Конец игры** / **Ещё раз**.

## Веб-версия

Та же игра в браузере (HTML5 Canvas), без сборки и npm.

1. Откройте файл `web/index.html` в браузере  
   или поднимите статику, например: `python3 -m http.server -d web 8080` и зайдите на http://localhost:8080/
2. На телефоне: держи и веди палец влево-вправо (огонь сам).  
   На десктопе: мышь влево-вправо с зажатой кнопкой, или **A/D** / стрелки, **Пробел** — огонь.
3. Рекорд сохраняется в `localStorage` браузера.

Файлы: `web/index.html`, `web/game.js`, `web/style.css`.

## Сборка

Требуется Android SDK (compile/target SDK 35, minSdk 26).

```bash
./gradlew assembleDebug
```

Готовый APK:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## Технологии

- Kotlin, single-module Gradle
- Пакет: `com.kotenass.skyburst`
- SurfaceView + игровой цикл на Canvas
- Веб: чистый HTML5 Canvas (без сборки)
- Без рекламы, бэкенда, биллинга и аналитики
